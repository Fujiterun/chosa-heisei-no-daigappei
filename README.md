# 調査：平成の大合併と学びの場

平成の大合併（1999〜2010年）が、博物館・図書館・公民館などの社会教育施設と、小中学校に何をもたらしたのか。政府統計・国会会議録・公表資料にもとづき、事実関係を網羅的に整理した調査報告です。

**📄 レポートを読む → https://fujiterun.github.io/chosa-heisei-no-daigappei/**

---

## 調査結果の要点

| | |
|---|---|
| **3,232 → 1,718 団体** | 市町村数は11年で約47％減少（1999年3月→現在） |
| **−31.6%** | 公民館数（平成11年度19,063館 → 令和6年度13,031館） |
| **+31.2% / +28.6%** | 同期間の図書館・博物館は逆に増加 |
| **−72.5%** | 社会教育主事（平成14年度5,383人 → 令和6年度1,481人） |
| **r = 0.26** | 都道府県別の合併進捗率と小中学校廃校率の相関（弱い） |

### 主な発見

1. **社会教育施設は一律に減ったわけではない。** 公民館だけが3割減る一方、図書館は31％増、博物館は29％増。合併が直撃したのは「小規模自治体が密に配置していた施設」でした。

2. **合併の痕跡は「設置者」に最も鮮明に残る。** 平成14→17年度に町村立公民館が3,994館減り、市立が3,190館増加。設置者の付け替えは合併以外に説明がつきません。

3. **影響が現れたのは合併の数年後。** 公民館の減少率がピークを迎えたのは合併集中期（平成16・17年度）ではなく、その3〜6年後。廃校発生数のピークも平成24年度でした。

4. **学校統廃合の主因は合併ではない。** 都道府県別に検証すると相関は弱く（r=0.26）、合併率最低の北海道が廃校数最多、合併率62％の滋賀県が廃校率最低。少子化が主因で、合併は加速要因にとどまります。

5. **施設より「人」の減り方が急だった。** 施設が3割減る間に、社会教育を企画・指導する専門職は7割超が失われました。
